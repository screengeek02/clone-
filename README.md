# CleanNow Web App (MVP Landing + Interactive Demo)

This repository now contains a lightweight web app prototype for **CleanNow**, an Uber-style on-demand cleaning platform.

## What's Included

- A responsive marketing + product overview page
- Interactive role tabs for:
  - Client App
  - Cleaner App
  - Admin Dashboard
- Instant cleaning price estimator (demo logic)
- Booking flow + rollout strategy sections

## Run Locally

Because this is a static web app, you can run it with any local server.

### Option 1: Python

```bash
python3 -m http.server 4173
```

Then open: <http://localhost:4173>

### Option 2: VS Code Live Server

Open `index.html` with Live Server.

## Files

- `index.html` – main app structure/content
- `styles.css` – visual design and responsive layout
- `script.js` – role tabs and price estimator interactivity
