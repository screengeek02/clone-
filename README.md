# VitalSpring Static Marketing Site

This remake uses **only HTML, CSS, and JavaScript** (no framework/runtime).

## Run locally
From repo root:

```bash
python -m http.server 4173
```

Then open `http://localhost:4173`.

## Structure
- `index.html` (home)
- route folders with `index.html` files for each page
- `assets/css/styles.css` shared design system + components
- `assets/js/app.js` shared navigation, interactions, and accessibility behaviors
- `robots.txt` and `sitemap.xml`
